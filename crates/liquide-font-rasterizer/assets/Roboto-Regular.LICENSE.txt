This font file (Roboto-Regular.ttf) is vendored into the
liquide-font-rasterizer crate and embedded into the binary via
`include_bytes!` so the desktop environment always has a real
proportional UI font available as a last-resort fallback, even when
the on-disk `assets/fonts/` directory is empty (i.e. when
`scripts/download-fonts.ps1` has not been run).
