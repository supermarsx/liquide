# LiquiDE Documentation Index

This directory is the canonical home for project documentation.

## Core Documents

- `docs/QUICK_START.md` - Fast setup and common workflows.
- `docs/ARCHITECTURE.md` - High-level system architecture.
- `docs/RENDERING_PIPELINE.md` - End-to-end rendering stages.
- `docs/GAP_ANALYSIS.md` - Current implementation gap and completion status.
- `docs/production-readiness.md` - Current readiness notes and remaining risk areas.

## Specifications

- `docs/specs/spec.md` - Primary server/desktop specification.
- `docs/specs/spec-protocol-formal.md` - Wire protocol, channels, schemas, and conformance rules.
- `docs/specs/spec-client.md` - Native client behavior and client-side configuration.
- `docs/specs/spec-build.md` - Build, CI, nightly, and release target policy.
- `docs/specs/spec-performance.md` - Performance SLOs, workloads, benchmarks, and capacity planning.
- `docs/specs/spec-observability.md` - Metrics, logs, traces, dashboards, alerts, and runbooks.
- `docs/specs/spec-threat-model.md` - Security model, threat analysis, and audit-event schema.
- `docs/specs/` - Additional gateway, management, system, settings, update, interop, accessibility, add-on, and theme specs.
- Configuration defaults are currently documented in the specs; the generated configuration-reference artifacts described in `docs/specs/spec.md` §27a are planned targets and are not checked in under `docs/` today.

## Reports

- `docs/reports/README.md` - Historical implementation reports, parity analyses, and point-in-time status snapshots.

## Archive

- `docs/archive/README.md` - Superseded baseline documents retained for historical reference.
